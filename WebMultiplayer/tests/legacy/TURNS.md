# 双人回合与计分

使用 start_room_test.bat，A创建、B加入，房主点击开始；服务器随机选择A或B先手。界面显示当前玩家、已投次数、保留状态及服务器计算的分数。

轮到自己时投掷；停止后点击五个骰子按钮保留/取消，下一投仅重投未保留骰子。最多三投，可以提前在下拉框选择尚未填写的项目，点击“记分并结束回合”。记分复用 rules.gd，全部24个玩家回合后按原规则结算。

room/match_state.gd保存并校验回合、次数、保留、点数与分数；room/server.gdtests连接座位、请求序号、回合号和参数。非当前玩家、物理运行中、超次数、重复请求、旧回合、已填项目、附带伪造点数均被拒。每个座位的请求序号保留到重连，不通过房间码辨认玩家。

临时掉线时暂停新操作，保留两分钟座位；恢复原标签页可继续原回合与次数。已认证的新连接可接替旧连接，旧连接失去控制权。主动退出或两分钟未恢复则关闭对局，不增加弃权计分规则；服务器重启不保存对局。

测试：服务器运行时 node room/turns_test.js（本机Node路径见start.ps1）执行真实物理和37项协议检查；room/match_state_test.gd检查两种先手下的24回合及既有规则。测试不输出会话令牌。
