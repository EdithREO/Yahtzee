# 公网双人 Web 游戏

## 启动、地址和停止

1. 双击 `F:\GA\YachtDuel\start_public_test.bat`。已绑定本机 cpolar 账号，无需重复登录。
2. 等窗口出现 `PUBLIC GAME: https://.../`，把这条完整 HTTPS 地址发给另一名玩家。隧道启动和日志刷新可能需要几十秒。
3. 当前地址也保存在 `%LOCALAPPDATA%\YachtDuel\public-origin.txt`；后台启动日志为同目录 `launcher.log`。不要使用旧截图或旧聊天中的地址作为永久地址。
4. 停止：在启动窗口按 Enter、关闭该窗口，或双击 `F:\GA\YachtDuel\stop_room_test.bat`。停止脚本仅通知本项目，不按进程名终止其他程序。
5. Windows 主机需要持续开机、联网且不进入睡眠。服务器停止后，当前房间和对局会消失，重启需重新建房。

## 异地双人tests

1. A 用电脑，B 用另一处网络，或手机关闭 Wi-Fi 改用移动数据。
2. 两边访问同一条最新 HTTPS 地址。首次需下载约 24 MB 的压缩网页引擎和游戏包，等双方都看到骰盘再投掷。刷新可使用校验缓存。
3. A 创建房间，将六位房间码交给 B；B 加入，双方应显示 2/2，A 点击开始。
4. 服务器随机先手。当前玩家投掷，双方观察相同的弹跳和旋转，核对最终五颗点数。用上方升序图标或实物骰子保留、取消，保留骰应移到右侧。继续投掷、记分并交换回合。
5. B 刷新页面，应恢复原座位、次数和保留状态。短暂断网再恢复，应自动重新连接；服务器仍运行时，离线座位保留 2 分钟。
6. 发起重新开始，由对方先拒绝，确认对局保留；再同意，确认双方同时重置。
7. 关闭服务器，已打开的页面应显示“与服务器连接已断开（网络中断或服务器已关闭）”。断网与关服无法仅从浏览器准确区分，提示明确列出两种情况。

## 架构与配置

浏览器 HTTPS/WSS → cpolar → 127.0.0.1:8765 网页代理 → 127.0.0.1:18766 Godot 权威服务器。

Windows 执行原有真实刚体物理和计分。客户端只插值播放采样及权威最终姿态。20 Hz 采样、150 ms 缓冲、房间/会话令牌/回合校验继续复用。游戏界面直接继承当前本地 game.gd；Windows EXE 本阶段未修改。

账号令牌仅位于 `%USERPROFILE%\.cpolar\cpolar.yml`；客户端位于 `%LOCALAPPDATA%\YachtDuel\tools\cpolar.exe`，不在project。只创建指向游戏端口的 HTTP 隧道；未启动配置里的远程桌面或其他示例隧道。代理只接受精确的当前公网域名及同源 HTTPS Origin。管理端口不通过隧道public。

随机地址可能在重启隧道后变化：启动器读取本次 cpolar 日志、自动更新代理白名单并打印新地址，无需修改客户端。两人必须改用同一个新地址。跨域地址不能读取旧域的 sessionStorage，因此换域后不能保证自动恢复原座位，建议重新建房；同域短时断网可恢复。当前不依赖固定域名或付费功能。

游戏包重新导出后，在project根目录运行本机 Node：`node room/compress_viewer.js`，生成 gzip 文件。代理检测压缩文件时间，过期时回退原文件；浏览器缓存每次校验，不会永久使用旧包。

## 本阶段实测与限制（2026-11-04）

- Godot 两个 Web 导出成功，脚本解析无错误；环境曾有根证书存储读取报错，未阻断导出。
- 既有 44 项双人协议回归通过，包含权威物理、三投/回合、保留、刷新/重连、计分和重开双方确认。
- 本地两个浏览器使用最新界面：同次投掷五骰最终位置/四元数/点数完全一致，朝上识别错误 0；约 144 FPS，平均帧时间约 6.94 ms。
- 真实公网 HTTPS 返回 200，两个公网浏览器 WSS 建房/加入/开始正常。公网协议测试双端 58 帧逐帧一致，最终五骰姿态与点数一致。
- 公网 WSS 持续 120.3 秒，116 次 pong，测得最大 ping 往返约 52.3 ms，断线后原座位和点数恢复。短测不能证明数小时或所有运营商网络稳定。
- 两浏览器同时下载未压缩大包时曾出现轨迹测试 30 秒超时。加入 gzip 后 wasm 39,514,754 → 10,153,810 字节，pck 13,688,684 → 13,579,671 字节；本地压缩响应及缓存 304 已tests。首次加载仍会占用带宽，等待所有客户端加载完再投掷。
- source文件/用户配置无法通过静态文件路由下载；未知 Host 返回 403，错误 Origin WebSocket 被拒绝。
- 已tests服务器关闭可见提示、重启后旧房间返回首页且说明需要重建；启动/重复启动/停止/端口释放通过。
- 尚未完成两个真实不同网络的实体设备测试。压缩后新公网域名的浏览器完整游戏复测，被自动审批系统因使用额度上限拒绝，未绕过；不能称该项通过。需要用户按上述步骤实测。

## 服务器source版本检查（2026-11-05）
启动器会记录本次载入的服务器source指纹。重复启动时若显示 OLD or unverified source，表示更新尚未载入：请结束当前对局后先运行 stop_room_test.bat，再运行 start_public_test.bat。不会为了更新强行结束正在进行的对局。网页更新可刷新生效，碰撞音效标记等服务端更新必须由新服务器进程载入。
