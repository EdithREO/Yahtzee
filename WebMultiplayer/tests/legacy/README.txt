局域网房间测试

1. 双击项目根目录 start_room_test.bat。窗口显示自动识别的 LAN address；有多个网络时按提示选对应网络。
2. Windows 本机和其他电脑或安卓手机使用同一局域网，在各自浏览器打开窗口显示的地址。手机 Wi-Fi 与本机有线网络需要属于同一局域网。
3. A 创建房间，B 输入房间码加入；双方确认 2/2，A 点击开始。断线后在两分钟内打开原标签页或刷新以恢复座位。
4. 测试结束，在启动窗口按 Enter 关闭服务，再按任意键退出。服务器重启后房间清空。

网页代理只绑定选定的局域网 IPv4 和本机回环地址，Godot 房间服务器只绑定本机。网页通过同源 /ws 连接。
当前电脑以太网地址为 192.168.1.3，地址可能变化，以启动窗口为准。当前 Windows 公用网络配置下已存在针对 Node 程序的入站 TCP 允许规则；实际跨设备连接尚待tests。
如果另一台设备无法连接，先确认网络在同一网段且路由器未启用客户端隔离，再检查防火墙。若没有适用规则，可由管理员以 PowerShell 添加仅 TCP 8765、当前网络配置文件、LocalSubnet 的入站允许规则；无需开放 18766。不要关闭防火墙。
依赖本机 Godot 4.7.2 Steam 版及 Codex 自带 Node.js，路径见 start.ps1。本阶段使用明文，仅供可信局域网测试；尚未配置公网或 TLS。
